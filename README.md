# FPGA 学习日志

这里记录 FPGA 就业方向的练习项目。每个项目都单独放在自己的文件夹中，便于学习、仿真、烧录和复盘。

## 项目目录

| 文件夹 | 内容 |
|---|---|
| [`学习日志/交通灯`](学习日志/交通灯) | 交通灯状态机、按键消抖、模式切换和 Vivado 工程 |
| [`学习日志/UART`](学习日志/UART) | UART 收发、FIFO 缓冲、回环功能和自检仿真 |
| [`学习日志/FPGA参数存储系统`](学习日志/FPGA参数存储系统) | UART 参数配置、CRC32、SPI NOR Flash 双备份保存和上电恢复 |

后续课程会继续在 `学习日志` 下创建新的独立项目，不覆盖已经完成的代码。
