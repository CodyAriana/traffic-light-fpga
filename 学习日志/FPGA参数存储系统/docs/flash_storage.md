# Flash 双备份设计

参数区使用两个独立的 4 KB sector：`0xFF0000` 和 `0xFF1000`。每个 sector 只保存一条 64 字节记录。

记录包含 MAGIC、格式版本、递增序号、11 字节参数、CRC32 和最后写入的 COMMIT 标记。上电时只有 MAGIC、版本、长度、CRC32、COMMIT 都正确的记录才算有效；两条都有效时选择序号较新的那条。

保存流程：

1. 读取并确定当前有效 slot。
2. 选择另一个 slot 作为目标。
3. 擦除目标 sector。
4. 写入记录主体，暂不写 COMMIT。
5. 回读并检查 CRC32。
6. 单独写入 COMMIT。
7. 再次回读确认，最后切换 active slot。

因此掉电发生在写入中间时，旧记录仍然保留；新记录只有在完整验证后才会成为有效记录。所有 Flash WIP 轮询都有超时计数器，避免硬件异常导致状态机永久卡住。
